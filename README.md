# MY RADIO iOS – Retro Design Integrated Version

この版は、4番のレトロデザインをベースに、既存の個人設定・話題選択・声選択・モーニングコール・AI放送生成機能を統合した版です。

主な変更点
- ヘッダータイトルを **MY RADIO** に統一
- サブタイトルを **世界に1つ、あなただけの放送局** に変更
- 全体配色をレトロ調（ブラウン・ゴールド）へ変更
- ホーム画面の文言を「AI」前面から、放送づくり中心の表現へ調整
- 既存のデータ入力・番組生成・音声再生機能は維持
